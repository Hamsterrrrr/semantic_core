Требования к файлу:
  • Столбцы должны включать: id, title, description, price, image_link, etc.
  • Первая строка должна содержать названия столбцов
  • Каждая строка - отдельный товар/услуга
О фидах

Фиды (feeds) - это файлы, содержащие структурированную информацию о товарах или услугах. Они используются для:

  • Интеграции с маркетплейсами и агрегаторами (Google Merchant Center, Яндекс.Маркет)
  • Создания товарных объявлений в рекламных сетях
  • Синхронизации данных между разными платформами

Сервис генерирует фиды в следующих форматах:

XML
Для большинства систем
CSV
Универсальный формат
JSON
Для API и веб-приложений
YML
Для Яндекс.Маркет
