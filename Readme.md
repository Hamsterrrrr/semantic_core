# Семантическое ядро для SEO

Проект для автоматизированного сбора и анализа семантического ядра сайта с использованием GPT и XmlRiver API.

## Возможности

- Анализ текстового содержимого сайта
- Автоматическое определение категорий с помощью GPT
- Генерация релевантных поисковых запросов
- Фильтрация нерелевантных запросов с помощью стоп-слов
- Сохранение результатов в CSV формате

      

## Основные возможности

- Интеллектуальное извлечение и анализ контента веб-страниц
- Автоматическое определение тематических категорий с помощью GPT
- Продвинутый сбор поисковых запросов через XmlRiver API
- Умная фильтрация нерелевантных запросов с использованием динамических стоп-слов
- Гибкий экспорт результатов в CSV и Excel с настраиваемым форматированием
- Подробная логика обработки ошибок и повторных попыток
- Асинхронная обработка для высокой производительности

## Настройка
Создайте файл .env в корневой директории проекта:
XMLRIVER_USER_ID=ваш_id
XMLRIVER_API_KEY=ваш_ключ
LOG_LEVEL=INFO
SAVE_DEBUG_FILES=False

Использование

python main.py

# Запуск с указанием URL
python main.py https://example.com/

## Результаты
Программа создает следующие файлы:
semantic_core_results.csv - CSV-файл с результатами
semantic_core_results.xlsx - Excel-файл с форматированием (если установлен openpyxl)

## Генерация фидов для товаров

Проект также включает функционал для генерации товарных фидов в различных форматах:

- XML фид для маркетплейсов
- YML фид для Яндекс.Маркета 
- CSV фид для импорта в таблицы
- JSON фид для API интеграций

### Поддерживаемые категории товаров:

- Одежда и обувь (clothing)
- Электроника (electronics) 
- Продукты питания (food)
- Книги и медиа (books)
- Мебель (furniture)

Для каждой категории поддерживаются специфичные атрибуты товаров.

### Использование генератора фидов:

1. Загрузите файл с данными товаров (CSV или Excel)
2. Выберите категорию товаров
3. Нажмите "Создать фиды"

Результаты будут доступны для скачивания после обработки.

### Требования к файлу с данными:

- Обязательные столбцы: id, title, description, price, image_link
- Первая строка должна содержать названия столбцов
- Каждая строка описывает отдельный товар/услугу

### Специфичные атрибуты по категориям:

#### Одежда и обувь (clothing)
- size - размер
- color - цвет
- gender - пол
- material - материал
- season - сезон
- pattern - узор/принт

#### Электроника (electronics)
- cpu - процессор
- ram - оперативная память
- storage - объем накопителя
- screen_size - размер экрана
- warranty - гарантия
- weight - вес
- dimensions - габариты

#### Продукты питания (food)
- expiration_date - срок годности
- ingredients - состав
- nutrition_facts - пищевая ценность
- weight - вес
- storage_conditions - условия хранения

#### Книги и медиа (books)
- author - автор
- isbn - ISBN
- publisher - издательство
- language - язык
- pages - количество страниц
- publication_date - дата публикации

#### Мебель (furniture)
- width - ширина
- height - высота
- depth - глубина
- weight - вес
- material - материал
- style - стиль
- assembly_required - требуется сборка

### Форматы выходных файлов:

- XML: стандартный формат для маркетплейсов
- YML: формат Яндекс.Маркета с расширенными атрибутами
- CSV: табличный формат для импорта в Excel/Google Sheets
- JSON: формат для API интеграций

### Обязательные поля
Эти поля должны присутствовать в любом CSV-файле для конвертации в YML:
| Поле в CSV | Элемент в YML | Описание | Пример |
|------------|---------------|----------|--------|
| id | id (атрибут в <offer>) | Уникальный идентификатор товара | ID12345 |
| title | <name> | Название товара | Смартфон Samsung Galaxy S21 |
| price | <price> | Цена товара | 59990.00 |
| currency | <currencyId> | Валюта цены | RUB |
| picture | <picture> | URL изображения товара | https://example.com/images/s21.jpg |
| category | <categoryId> | ID категории товара | 15 |
| availability | available (атрибут в <offer>) | Наличие товара | true или false |

### Пример преобразования в YML
Строка для смартфона из примера выше будет преобразована в YML следующим образом:
<offer id="1001" available="true">
  <name>Смартфон Samsung Galaxy S21</name>
  <description>Мощный смартфон с 6.2" экраном</description>
  <price>59990.00</price>
  <currencyId>RUB</currencyId>
  <categoryId>Электроника/Смартфоны</categoryId>
  <picture>https://example.com/s21.jpg</picture>
  <brand>Samsung</brand>
  <model>SM-G991B</model>
  <param name="цвет">Черный</param>
  <param name="процессор">Exynos 2100</param>
  <param name="память">128 ГБ</param>
  <param name="экран">6.2"</param>
</offer>
Вы можете добавить любые произвольные параметры, используя префикс param_ в заголовке столбца CSV файла.
