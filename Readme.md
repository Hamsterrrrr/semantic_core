# Семантическое ядро для SEO

Проект для автоматизированного сбора и анализа семантического ядра сайта с использованием GPT и XmlRiver API.

## Возможности

- Анализ текстового содержимого сайта
- Автоматическое определение категорий с помощью GPT
- Генерация релевантных поисковых запросов
- Фильтрация нерелевантных запросов с помощью стоп-слов
- Сохранение результатов в CSV формате

      

## Основные возможности

- Интеллектуальное извлечение и анализ контента веб-страниц
- Автоматическое определение тематических категорий с помощью GPT
- Продвинутый сбор поисковых запросов через XmlRiver API
- Умная фильтрация нерелевантных запросов с использованием динамических стоп-слов
- Гибкий экспорт результатов в CSV и Excel с настраиваемым форматированием
- Подробная логика обработки ошибок и повторных попыток
- Асинхронная обработка для высокой производительности

## Настройка
Создайте файл .env в корневой директории проекта:
XMLRIVER_USER_ID=ваш_id
XMLRIVER_API_KEY=ваш_ключ
LOG_LEVEL=INFO
SAVE_DEBUG_FILES=False

Использование

python main.py

# Запуск с указанием URL
python main.py https://example.com/

## Результаты
Программа создает следующие файлы:
semantic_core_results.csv - CSV-файл с результатами
semantic_core_results.xlsx - Excel-файл с форматированием (если установлен openpyxl)
